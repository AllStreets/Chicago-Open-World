# Phase 2.5 — Expanded City & Accurate Skyline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Grow the world from the 4 km² core to ~110 km² (Addison → 35th St, Western → the lake) with every building current to 2026, an accurate top-50 skyline, hand-shaped top-25 landmarks + 3 stadiums, and the full Phase 2 beauty treatment everywhere — streamed so it still runs at 60 fps.

**Architecture:** OSM becomes the building source (City footprints froze in 2015) and City data enriches it. A curated `skyline.json` (from Wikipedia) validates heights; `heroes.json` shapes landmarks with crown primitives. The pipeline emits one compressed multi-layer glb per 500 m tile plus an LOD1 glb and a sidecar (meta, trees, props, columns). The app streams tiles by distance, assigns materials by mesh name, and instances trees/props per tile.

**Tech Stack:** Phase 2 stack + @gltf-transform/functions & extensions 4.5 (weld, meshopt), meshoptimizer 1.3, polygon-clipping 0.15.

**Spec:** `docs/superpowers/specs/2026-09-28-chi-atlas-open-world-design.md` — **Addendum A** (binding for this plan), plus §4–§8.

## Global Constraints

- Bounds `WORLD_BBOX = { s: 41.826, w: -87.695, n: 41.952, e: -87.595 }`; `RING0_BBOX` unchanged (downtown core, used for defaults/intro).
- Projection, tile size 500 m, tile key `"{tx}_{tz}"`, floor 3.8 m, `MAX_HEIGHT_M` 530 — unchanged.
- Height order (OSM height → OSM levels → City stories → type default): defaults `house 8, detached 8, semidetached_house 8, terrace 9, garage 4, garages 4, shed 3, apartments 12, residential 10, commercial 8, retail 6, industrial 10, warehouse 10, church 16, school 12, hospital 20, stadium 25, yes 9`.
- LOD0 ≤ 1600 m, LOD1 ≤ 7000 m from camera target; 15 % hysteresis; dispose LOD0 beyond 2200 m.
- Budgets: first load < 60 MB; `app/public/world` < 200 MB; HIGH ≤ 300 draw calls and ≤ 4 M triangles/frame incl. shadow pass.
- Camera target clamped to the world bbox (projected, −200 m margin); camera–target distance ≤ 6000 m; min altitude 30 m.
- Every task ends with commit + push to `origin main`. No emojis; Remix icons; CHI tokens.

## Review Focus

- **OSM multipolygon buildings with inner courtyards and multiple outers** (e.g. Merchandise Mart, courtyard apartment blocks) → every outer extruded, inners as holes, no roof over courtyards. Pinned in Task 2 (`osmBuildingPolys` test).
- **A landmark whose OSM geometry is missing or renamed** → build fails loudly naming it (never silently ships a skyline without Willis). Pinned in Task 3 (`validateSkyline` test).
- **Roads/parks crossing tile borders** → no gaps or double-drawn overlaps at seams; each segment in exactly one tile, polygons clipped. Pinned in Task 5 (`clipPolysToTile`, `splitLineByTiles` tests).
- **Fast camera moves across the city** (minimap click to Wrigleyville) → tiles load at LOD1 first, never a hole to the horizon; LOD0 pops in near; memory stays bounded (LOD0 disposed when far). Pinned in Task 7 (`planTiles` hysteresis/limit tests).
- **Compression altering shader attributes** (`_FACADE` 8 = parapet, `_SEED`, `_BLDG`) → exact values after decode. Pinned in Task 5 (`writeTileGlb` round-trip test).

export const WORLD_BBOX = { s: 41.826, w: -87.695, n: 41.952, e: -87.595 }
export function chunkBBox({ s, w, n, e }, nx, ny) {
  const out = []
  for (let j = 0; j < ny; j++) for (let i = 0; i < nx; i++)
    out.push({ s: s + ((n - s) * j) / ny, n: s + ((n - s) * (j + 1)) / ny, w: w + ((e - w) * i) / nx, e: w + ((e - w) * (i + 1)) / nx })
  return out
}

### Task 4: Crown primitives + hero specs

**Files:** Create `pipeline/lib/crowns.js`, `pipeline/lib/heroes.js`, `pipeline/data/heroes.json`, tests `crowns.test.js`, `heroes.test.js`; modify `pipeline/lib/shapes.js` (delegate to heroes), `pipeline/lib/extrude.js` (export `extrudeMesh` for raw triangle lists).

**Interfaces:**
- Crown generators return raw meshes `{positions, normals, uvs}` (façade/roof material by normal) placed in world metres:
  - `spire({ at:[x,z], base, top, r0, r1=0, sides=12 })` — tapered cylinder/cone.
  - `antenna({ at, base, top, r=0.9 })` — thin cylinder (sides 8).
  - `pyramid({ ring, base, top })` — hip roof from a convex ring to its centroid apex.
  - `drum({ at, base, top, r, sides=24 })` — cylinder with flat cap.
  - `sloped({ ring, base, lowTop, highTop, dir:[dx,dz] })` — prism whose roof plane rises along `dir` (the Crain "diamond" cut).
- `heroes.json` entry: `{ "key", "name", "match": { "osmId"?: number, "lat", "lon" }, "heightM"?, "facade"?: familyName, "tint"?: "dark"|"green"|"silver"|"blue", "taper"?: {topScale}, "tiers"?: [{ "scale": 0.8, "from": 200, "to": 300 }], "crowns": [ { "type": "spire"|"antenna"|"pyramid"|"drum"|"sloped", …params relative to building roof/centroid } ] }`.
- `seedForTint(tint) → number` — inverse of the shader's `fract(seed*3.7)` buckets (dark < 0.28, green < 0.5, silver < 0.78, blue ≥ 0.78) returning a seed whose bucket matches.
- `applyHero(building, spec) → pieces` (extrusion pieces) + `extraMeshes` (crown meshes); also sets `building.facade`/`seed` overrides consumed by the build.
